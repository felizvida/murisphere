# Murisphere Release v0.4.1

Release date: 2026-04-24

## Highlights
- Expanded the chat-first operating layer around daily technician, facility-manager, and researcher workflows.
- Added chat prompts for weaning queues, mortality follow-up, room batch cage-card printing, quota pressure, request SLA review, sample results, animal reservations, and project closeout shortcuts.
- Kept the traditional visual workspace active as the richer surface for dashboards, cage visualization, pedigree, analytics, compliance review, exports, and batch work.
- Updated the role-based tutorial with simulated-data prompt responses for the new chat workflows.

## Reliability And Compliance
- Added integration coverage for first-principles role workflows through `/api/chat`.
- Audit-logged explicit chat-based animal reservation actions.
- Ignored the generated alert-fixture JSON artifact so local audit runs do not pollute release status.
- Refreshed operational audit artifacts for QR, UI clickability, alert coverage, and cage-card layout checks.
