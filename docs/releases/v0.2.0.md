# Murisphere Release v0.2.0

Release date: 2026-03-05

## Highlights
- Fixed cage-card QR rendering and phone scan reliability.
- Removed client-side CDN dependency for QR/barcode generation.
- Added server-generated card assets:
  - `GET /api/assets/qrcode.png?v=...`
  - `GET /api/assets/barcode.svg?v=...`
- Added diagnostic program `qrcode_diagnostic.py` for end-to-end validation.
- Extended integration tests to verify QR PNG/barcode SVG output and no CDN regressions.

## Problem Solved
Printed cage cards were showing blank/broken QR images in restricted networks where CDN script loading failed. This prevented phone camera scans from opening cage info.

## Technical Changes
- Backend now generates QR as PNG using `qrcode[pil]`.
- Backend now generates CODE128 barcode as SVG using `python-barcode`.
- Frontend card rendering now uses direct image URLs from local API endpoints.
- Removed external script tags for `qrcode` and `JsBarcode`.

## Validation
- `python qrcode_diagnostic.py` -> passed.
- `python -m unittest discover -s tests -p 'test_*.py' -q` -> passed.

## Upgrade Notes
1. Install updated dependencies: `pip install -r requirements.txt`
2. Restart application service.
3. Regenerate printed cage cards.
4. Verify phone scan flow with a printed card.
