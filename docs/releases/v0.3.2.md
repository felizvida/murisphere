# Murisphere Release v0.3.2

Release date: 2026-03-05

## Highlights
- Added a phone-first default dashboard immediately after login with visual KPIs, alert pressure, and task load.
- Made cage and project names clickable across tables and alert views, with visual drill-down inspectors.
- Fixed silent session-expiry behavior so expired sessions now reset auth state and prompt re-login.
- Hardened public scan security by escaping all rendered values to prevent stored XSS injection.
- Completed public scan payload parity (`genotypeSummary`, `dob`, `protocol`) for consistent cage details.
- Expanded cage search to include project code/title, protocol, and lab metadata.

## Compliance and Reliability Fixes
- Added explicit UI error/status surface for action failures instead of silent button no-ops.
- Added CI hardening for cage-card audit browser variability on GitHub runners.
- Kept strict static cage-card checks while allowing render-step skip only for browser launch failures in CI.
