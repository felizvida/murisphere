# Murisphere Release v0.3.1

Release date: 2026-03-05

## Highlights
- Refined cage-card presentation to prevent table text crossover and improve print professionalism.
- Added an automated cage-card layout audit program to verify no header/value overflow between columns.
- Switched tutorial PDF generation to Pandoc + XeLaTeX workflow.
- Updated PDF asset conversion to use `rsvg-convert` and removed Chrome print-to-PDF dependency.
- Regenerated tutorial PDF without local file-path/footer leakage.

## Cage Card Improvements
- Updated card table flow and overflow guards for robust column isolation.
- Tightened table rendering behavior for long genotype and date text.
- Improved visual hierarchy and print style consistency for professional vivarium use.
