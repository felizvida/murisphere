# Murisphere Release v0.3.0

Release date: 2026-03-05

## Highlights
- Expanded workflow coverage across technician and facility-manager daily operations.
- Added enterprise-parity modules for census, orders, protocol versioning, billing review/adjustment, vet cases, attachments, and e-signatures.
- Added alerting and visualization improvements for faster in-room and oversight decision making.
- Added synthesized alert coverage verification tooling and tests.
- Updated tutorial and user documentation to be workflow-first, including explicit phone scanning of printed QR cage cards.

## Notable Functional Additions
- Compliance and alerting:
  - alert feed, acknowledgment, streaming updates, and dispatch channels
  - protocol deviations, quarantine workflows, mortality + necropsy tracking
- Research planning:
  - recommendation generation and decision lifecycle
  - planner scenarios and risk/deficit evaluation
- Operations:
  - facility request workflow and SLA summary
  - billing engine/rules/statements + review and adjustments
  - facility benchmark and chargeback endpoints
- Animal lifecycle and colony execution:
  - breeding pairs productivity tracking
  - health rounds, welfare workflows, euthanasia reporting
  - sample lifecycle and genotyping order/callback pipeline

## Documentation Updates
- Refreshed: README, API reference, architecture, runbooks, security/compliance, testing strategy, user guide.
- Added/updated workflow coverage matrix and release checkpoint.
- Updated tutorial source + HTML + PDF references.
