Step-by-Step: Phone Scan of Printed Card

  1. In Cages, set Scan Base URL to a phone-reachable host (LAN IP or production domain).
  2. Click Generate + Print and verify the printed card contains a solid QR square.
  3. Open the phone camera and point it at the printed QR code.
  4. Tap the detected link banner to open cage info in browser.
  5. Tap Open Murisphere (login for edits), verify cage ID, then save updates.
  6. If Wi-Fi drops, save actions are queued and auto-retried on reconnect. Confirm retry sync before ending rounds.

Critical Safety Checks

  • ID first: never edit unless scanned cage ID matches printed card.
  • Protocol hard stop: if protocol is expired, editing is blocked until protocol assignment is corrected.
  • Queue awareness: if you see a queued-save message, reconnect and verify data synced before leaving the room.

Troubleshooting

  • No scan prompt: improve lighting and flatten the printed card.
  • Wrong page opens: correct Scan Base URL (never use localhost for printed cards).
  • Broken/blank QR: verify server endpoint /api/assets/qrcode.png?v=test loads.
  • Save blocked by protocol: check protocol expiry in Compliance tab and reassign valid protocol.
  • Queued save message: verify network, wait for auto-retry, then reload cage to confirm persisted values.
  • Slow open: retest on stronger room Wi-Fi.
