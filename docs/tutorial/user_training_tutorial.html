Murisphere Training

Mobile Scan Tutorial (Printed Cage Card)

Professional step-by-step guide for technicians and trainers.

Goal

Use a phone camera to scan a printed cage card and open the correct Murisphere cage record safely and quickly.

Cards use server-rendered QR/barcode images for reliable printing and scanning.

Figure A - Printed Card to Phone Flow (Illustration)

Step-by-Step: Phone Scan of Printed Card

  1. Set Scan Base URL to a phone-reachable host (LAN IP or production domain).
  2. Print cards from Generate + Print.
  3. Open your phone camera and point to the printed QR code.
  4. Tap the link banner that appears.
  5. Verify cage ID before editing.
  6. Tap Open Murisphere (login for edits).

Figure B - Troubleshooting (Illustration)

Trainer Checklist

  1. Demonstrate one full scan -> open -> verify -> edit -> save cycle.
  2. Require trainee to repeat with a second cage.
  3. Confirm trainee knows not to edit before cage ID verification.
