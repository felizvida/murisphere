1) Quick Start and Prerequisites

Core principle: cage-level speed and accuracy first. Use phone scan workflows in the room, then manager workflows for oversight and planning.

Technician PI/Manager Admin

  1. Sign in from phone or tablet.
  2. Set Scan Base URL to a phone-reachable host (LAN IP or domain).
  3. Print cage cards at 100% scale.
  4. Verify one sample scan before starting room rounds.

2) Mouse Technician Daily Workflows

2.1 Start-of-Shift Room Entry

  1. Open active alerts; identify high-severity cages first.
  2. Review due/overdue tasks for assigned rooms.
  3. Confirm protocol blocks are cleared before edits.

2.2 Phone Scan of Printed Card (Required)

  1. Open phone camera and scan printed QR (not the 1D barcode strip).
  2. Tap link banner to open cage page in browser.
  3. Verify cage ID and location before edits.
  4. Save count/status/note updates.

Never edit unless scanned cage ID matches printed card.

2.3 Cage Census and Reconciliation

  1. Start census session for room.
  2. Scan each cage and confirm observed M/F counts.
  3. Complete session and record mismatch notes.

2.4 Breeding Operations

  1. Create/manage breeding pairs (sire + dam + cage).
  2. Record timed mating / plug check / weaning events.
  3. Review pair productivity and retire non-productive pairs.

2.5 Health, Vet, Mortality, and Euthanasia

  1. Run health rounds and log findings.
  2. Open vet case and treatment plan as needed.
  3. Record mortality and flag necropsy if required.
  4. Record euthanasia events with method/reason/disposition.

2.6 Tagging and Sample Handling

  1. Apply animal tags (ear tag/chip/tube/well).
  2. Create sample record and sample code.
  3. Advance status: collected → shipped → received → resulted.
  4. Confirm chain-of-custody events are logged.

3) Facility Manager Daily Workflows

3.1 Morning Command Review

  1. Review alert feed and category distribution.
  2. Acknowledge or escalate unresolved alerts.
  3. Dispatch notifications for urgent items.

3.2 Capacity and Room Operations

  1. Check room/rack capacity and quota utilization.
  2. Review cage-space projection and consolidation suggestions.
  3. Prioritize cage wash and room transfer actions.

3.3 Recommendation Decisions

  1. Generate recommendations (e.g., consolidation, supply gap).
  2. Decision each item: accept, adjust, ignore, complete.
  3. Track decision outcomes for continuous improvement.

3.4 Planner Scenario Management

  1. Create scenario (target animals, needed-by date, cage constraints).
  2. Attach projects and required animal counts.
  3. Evaluate deficit/risk and review generated plan snapshots.

4) Regulatory and Compliance Workflows

  • Protocol expiration monitoring and hard-stop edit enforcement.
  • Deviation logging with CAPA and closure status.
  • Quarantine intake, release, and overdue monitoring.
  • Qualification-expiry monitoring for assigned procedures.
  • E-signature capture and attachment evidence for inspections.
  • Audit trail review for who/what/when changes.

5) Research Support Workflows

  • Pedigree exploration for multi-generation lineage decisions.
  • Genotyping order submission and callback result ingestion.
  • Mendelian ratio and genotype-deviation alert review.
  • Project-specific demand planning and supply-gap detection.
  • Cross-system exports (CSV/Excel/PDF/API jobs).

7) End-of-Shift / End-of-Day Checklists

Technician End-of-Shift

  1. Ensure queued offline writes are fully synced.
  2. Confirm all health findings and treatments are documented.
  3. Verify mortality/necropsy and euthanasia entries are complete.
  4. Close open census/round sessions.

Manager End-of-Day

  1. Clear or assign owners for all high-severity alerts.
  2. Review unresolved deviations and quarantine blocks.
  3. Approve/adjust recommendations and planner risk items.
  4. Export daily summary for audit and project stakeholders.

8) Troubleshooting and Escalation

  • No camera scan prompt: improve lighting and flatten printed card.
  • Camera reads barcode value only: scan the QR square, not the CODE128 bar pattern.
  • Wrong page opens: correct Scan Base URL; never use localhost for printed cards.
  • QR blank or broken: verify endpoint /api/assets/qrcode.png?v=test.
  • Protocol hard-stop: reassign valid protocol before edits.
  • Sample or callback mismatch: validate sample code uniqueness and provider callback token.
  • Planner risk high: open recommendation workflow and assign corrective action owner.
